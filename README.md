# Tampermonkey 用户脚本

个人 Tampermonkey 用户脚本集合，单个 `.user.js` 文件即产物，无构建步骤。

## 脚本列表

| 脚本 | 版本 | 说明 |
| --- | --- | --- |
| [浪潮云 CSS 工单自动转派](浪潮云CSS工单自动转派.user.js) | 1.0.1 | 勾选工单后按规则表匹配处理人员，自动分批完成批量转派 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开对应脚本的 raw 地址，Tampermonkey 会弹出安装页：

   https://raw.githubusercontent.com/jiebukai/Tampermonkey/main/浪潮云CSS工单自动转派.user.js

也可以把 `.user.js` 文件直接拖进浏览器窗口安装。

## 浪潮云 CSS 工单自动转派

适用站点：`https://css.cloud.inspur.com/platform/*`（工单查询页面）。

### 使用

1. 在工单列表勾选一张或多张工单
2. 右下角出现「自动转派 (N)」按钮，点击
3. 核对确认面板（每个工单对应的处理人员、分成几批）
4. 点「确认执行」

脚本会依次完成：批量转派 → 确认弹窗 → 搜索并选中处理人员（技能组自动带出）→ 填写处理描述 → 保存。

### 规则表

编辑脚本顶部的 `CONFIG.rules`，从上到下匹配，命中第一条即停止：

```js
rules: [
  { match: { '云中心': '重庆云中心' }, user: 'malei07' },
  { match: { '云中心': '四川省直云中心' }, user: 'yinhang01' },
],
description: '请老师处理',
```

- `match` 的键必须与工单列表表头文字完全一致（如 `工单标题`、`云中心`、`一级分类`、`产品线`）
- 值是字符串表示「包含」，写成 `/正则/` 表示正则匹配
- 多个条件为「且」关系
- 未命中任何规则的工单会被拦下并列出，不会静默跳过

### 行为说明

- 系统的批量转派一次只能指定一个处理人员，因此匹配到不同人员时会**自动按人员分组、逐批执行**；每批执行前脚本会重设勾选状态
- 任何一批失败会立即停止，提示已完成数量、失败人员和剩余批次
- 保存结果以抽屉关闭为准；失败时提示具体原因
